# zero-conformance

Conformance vectors for non-JS Zero clients, generated by running the JS
implementation. The Swift client (`swift/`) replays every file in `vectors/`.

- `pnpm run test` checks that the checked-in vectors match the current JS
  behavior.
- `pnpm run generate` rewrites them.

Each generator is a `*.test.ts` file under `src/` that calls `emitVectors`.
See `swift/DESIGN.md` for the vector layers.
